# REQ-256 Ansichten ohne Code definieren

**Als** Spielleitung **möchte ich** Ansichten global festlegen (welche Typen oder Felder sie zeigen), je Artikelart anpassen und eigene Ansichten anlegen, **damit** ich die Darstellung ändere, ohne zu programmieren.

## Akzeptanzkriterien

- Overview, Quick, Full, Print und Search sind im Register umbaubar, aber nicht löschbar.
- Eine Anpassung je Art (`adjust`: drop, hide, add, order) sagt nur die Abweichung.
- Eigene Ansichten (z. B. Handzettel) lassen sich anlegen und auf Kachel und Druck wählen.

## Bisheriger Wortlaut

> Ansichten ohne Code definieren: global je Ansicht festlegen, welche Felder (nach Typ bzw. Typ.Feld) erscheinen; ein Artikel zeigt davon, was er hat; je Artikelart überschreib- und anpassbar
