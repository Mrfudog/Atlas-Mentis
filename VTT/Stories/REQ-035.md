# REQ-035 Rolle je Kampagne

**Als** Verwaltung **möchte ich** dass ein Konto in jeder Kampagne eine eigene Rolle hat, **damit** wer in einer Runde leitet, in einer anderen mitspielen kann.

## Akzeptanzkriterien

- `campaign_member (campaign, user, role)` hält die Rolle; sie steht in keinem Artikel.
- Gepflegt wird sie auf der Kampagnenseite von Verwaltung und Leitung.

## Anmerkungen

Multi-author worlds

## Bisheriger Wortlaut

> Membership triples: user + scope (campaign/world/layer) + role
