# REQ-133 Marker, die zu Artikeln führen

**Als** Spielleitung **möchte ich** Marker auf die Karte setzen, die einen Artikel öffnen, **damit** Orte und Figuren auf der Karte nachschlagbar sind.

## Akzeptanzkriterien

- Ein Marker zeigt die Kurzansicht seines Artikels.

## Bisheriger Wortlaut

> Static tokens: reference markers linked to entities (pin opens article)
