# REQ-357 Regelgraphen wirken am Tisch

**Als** Spielleitung **möchte ich**, dass die Regelgraphen der laufenden Kampagne auf das reagieren, was am Tisch geschieht (Zugplan, Initiative, Karte, Inventar, Handwerk), und ihre Folgen als Angebot zeigen, **damit** Reaktionen wie Shield, Counterspell oder Sentinel nicht mehr vergessen werden und eine Regel als Artikel gepflegt wird statt im Code.

## Akzeptanzkriterien

- Zugplan, Initiative, Karte, Inventar und Handwerk senden Ereignisse; ausgewertet wird am Server mit dem gesiebten Stand, ohne `eval`.
- Eine Folge ist ein Angebot an die Spielerin oder die Leitung und wird bestätigt (wie im Zugplan, T-198); nichts ändert sich ohne Klick.
- Je Kampagne lassen sich Regelgraphen ein- und ausschalten, wie die Optionen in Rules & options.
- **Der Graph führt** dort, wo heute Code dasselbe anbietet (Gelegenheitsattacke, Reaktion zurück zu Beginn des Zugs, Fallen auf 0 Trefferpunkte): ist der Graph eingeschaltet, bietet nur er an; ist er aus, gilt der Code wie bisher. Nie beide.
- Eine Regel darf mehrere Auslöser haben (Sentinel 2014: eigener Gelegenheitsangriff trifft, Disengage, Angriff auf ein anderes Ziel).
- Fassungen einer Regel (2014, 2024) sind je ein Regelartikel in der Ebene ihres Buchs.
