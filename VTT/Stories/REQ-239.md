# REQ-239 Jedes Buch eine Ebene

**Als** Spielleitung **möchte ich** jedes Buch (PHB, MM, DMG, XGE …) als eigene Ebene, **damit** meine Kampagne genau die Bücher aufschaltet, die sie nutzt.

## Akzeptanzkriterien

- Je Quelle eine Ebene; Ids, Nummern und Namen des Grundstands bleiben.

## Bisheriger Wortlaut

> Jedes Buch eine eigene Ebene (PHB, MM, DMG, XGE …), statt einer Ebene für alles aus 5e.tools; eine Kampagne schaltet die Bücher auf, die sie nutzt
