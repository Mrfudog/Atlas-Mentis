# REQ-018 Wirkungen von Regeln beschreiben

**Als** Spielleitung **möchte ich** an einer Regel festhalten, was sie gewährt oder einschränkt, **damit** die Seite sie später anwenden kann.

## Akzeptanzkriterien

- Eine Regel trägt Wirkungen (z. B. `affects`); unbekannte Wirkungen werden übergangen.

## Bisheriger Wortlaut

> Rule effects format: effects[] with grants/constraints, open type list, consumers ignore unknown types
