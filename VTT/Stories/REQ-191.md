# REQ-191 Nichts still überschreiben

**Als** Spielleitung **möchte ich** dass ein fehlgeschlagenes Laden nie durch ein späteres Speichern überschrieben wird, **damit** ein Fehler keine Daten vernichtet.

## Akzeptanzkriterien

- Geschrieben wird nur gegen eine gelesene Revision.
- Ein Entwurf lässt sich herunterladen, wenn das Speichern scheitert.

## Anmerkungen

The lesson that nearly cost the campaign. In the old app a load error installs defaults and the autosave then overwrites everything 700 ms later. Not covered by REQ-155 backups — Stand: Fail-closed im Prototyp

## Bisheriger Wortlaut

> Fail-closed persistence: a failed load or migration must never be overwritten by a later autosave; the unreadable state is preserved and downloadable
