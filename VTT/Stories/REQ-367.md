# REQ-367 Verwaltung: Konten, Kampagnen und Inhalte

**Als** Verwaltung **möchte ich** in einer Seite Admin Konten, Kampagnen samt Zuweisung und die Inhalte, die ein Konto nutzen darf, verwalten, **damit** ich die Installation aus der Seite führe und Inhalte gezielt freigebe.

## Akzeptanzkriterien

- Reiter Accounts: anlegen, sperren, entsperren, Passwort-Link, Verwaltung vergeben, Figuren je Konto.
- Reiter Campaigns: anlegen, archivieren, Leitung und Mitglieder zuweisen, alle Kampagnen auf einen Blick.
- Reiter Content: Ebenen und Ebenengruppen je Konto freigeben (`app_user_content`, nie im Artikel); ohne Zeile gilt alles.
- Eine Leitung schaltet in ihrer Kampagne nur auf, was ihr freigegeben ist.

Entscheidung E-144.
