# REQ-349 Wie Blaupausen gelernt werden, ist eine Regeloption

**Als** Spielleitung **möchte ich** an der Kampagne wählen, wie eine Figur Blaupausen kennt, **damit** der Tisch nach Kibbles spielen kann (alles von Anfang an) oder nach eigener Regel (nur Beigebrachtes, oder nach Seltenheit).

## Akzeptanzkriterien

- Unter Rules & options › Crafting steht die Option „Known blueprints" mit drei Varianten:
  - **All** (Kibbles): jede Blaupause ist von Anfang an bekannt.
  - **Only taught** (Hausregel): bekannt ist nur, was der Figur beigebracht wurde — eine Information am Rezept, die sie kennt (REQ-218).
  - **By rarity** (Hausregel): bekannt ist jede Blaupause bis zu einer Seltenheit der Kampagne (Vorgabe: common), deren Werkzeug die Figur beherrscht, dazu alles Beigebrachte.
- Die Wahl gilt überall, wo „gelernt" zählt: Crafting-Reiter, Werkbank, Start eines Auftrags.
- Gerechnet beim Lesen; nichts wird an Figuren geschrieben.

## Anmerkungen

Zum Start von Nebelwacht: „By rarity" mit common — jede Figur kennt alle gewöhnlichen Blaupausen ihres Berufs.
