# REQ-008 Varianten einer Sache

**Als** Spielleitung **möchte ich** aus einem Artikel eine Variante machen, die auf das Original zeigt (z. B. ein besonderer Bogen aus einem Langbogen), **damit** Verwandtes verbunden bleibt, ohne dasselbe zu sein.

## Akzeptanzkriterien

- Die Kante `variantOf` verbindet Variante und Original.
- Ein Knopf legt eine Variante als Kopie mit der Kante an.

> Variant mechanism: copy with variantOf link
