# REQ-291 Leseansicht auf dem Board

**Als** Spielleitung **möchte ich** eine Leseansicht auf ein Board legen und Kapitel, Seiten oder Anker darin wählen, mehrere je Notiz, **damit** die Regel oder der Abschnitt, den ich brauche, auf dem Schirm offen liegt.

## Akzeptanzkriterien

- Eine Platzierung kann auf eine Stelle in einem Buch zeigen.
- Die Wahl ist eine Ansicht mit ihrer Konfiguration.
