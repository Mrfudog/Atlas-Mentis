# REQ-193 Gebiete auf der Karte

**Als** Spielleitung **möchte ich** Gebiete aus Formen (Rechteck, Kreis, Ellipse, Polygon) auf das Gitter legen, **damit** Herrschaftsgebiete sichtbar sind.

## Akzeptanzkriterien

- `territory` wird auf das Gitter gerastert.
- Gebiete gehen in Kartenbereichen auf (REQ-376): Art, Name, Sichtbarkeit, Ziel.

## Anmerkungen

Refines REQ-137, which is query-driven highlights rather than authored areas — Stand: `territory`

## Bisheriger Wortlaut
