# REQ-135 Tokens im Spiel

**Als** Spielleitung **möchte ich** Tokens, die nur in einer Sitzung oder für die Kampagne gelten (Kampfpositionen, vorübergehende Änderungen), **damit** die vorbereitete Karte unverändert bleibt.

## Akzeptanzkriterien

- Spiel-Tokens haben eine eigene Lebensdauer je Sitzung oder Kampagne.

## Bisheriger Wortlaut

> Play tokens: session- or campaign-scoped state objects (combat positions, temporary changes)
