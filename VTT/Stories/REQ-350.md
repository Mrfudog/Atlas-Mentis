# REQ-350 Eine Information gilt für eine Gruppe von Artikeln

**Als** Spielleitung **möchte ich** eine Information nicht nur an einem Artikel, sondern für eine ganze Gruppe festlegen — „der Trait aller Orcs“ —, **damit** ich Wissen über Völker, Arten und Gruppen einmal schreibe und es an jedem passenden Artikel gilt.

## Akzeptanzkriterien

- Eine Information trägt optional eine **Geltung** wie eine Ansicht (T-268): Typen, Bedingungen auf Felder und Kanten, auch „hat eine Kante auf diesen Artikel“ (Herkunft Orc, Unterarten eingeschlossen).
- Ohne Geltung gilt sie wie bisher für den Artikel, der sie über `knowledge` nennt.
- Das Zurückhalten am Server (`redactEntity`) zählt geltende Informationen wie angehängte.
