# REQ-301 Stilkonzept in der Verwaltung anpassen

**Als** Verwaltung **möchte ich** das Stilkonzept (Farben, Schriften) in einem Verwaltungsbereich anpassen, **damit** Änderungen am Aussehen keinen Code brauchen.

## Akzeptanzkriterien

- Die Werte des Stilkonzepts stehen als Einstellungen und wirken sofort.
