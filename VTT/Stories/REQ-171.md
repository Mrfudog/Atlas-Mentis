# REQ-171 Aktionen je Knoten

**Als** Spieler **möchte ich** an jedem Knoten eine Aktion je Figur aus einer Liste wählen (schleichen, herstellen, sammeln, rasten), **damit** Reisen Entscheidungen bietet.

## Akzeptanzkriterien

- `Party.actions` verbindet Figur und Regelartikel `kind: travel`.

## Anmerkungen

Stand: `Party.actions`: Figur → Regelartikel `kind: travel`

## Bisheriger Wortlaut

> Per-node action budget: one action per character per node from a configurable list (sneak, craft, forage, rest)
