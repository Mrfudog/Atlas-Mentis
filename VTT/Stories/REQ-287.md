# REQ-287 Regelsysteme als Behälter mit Optionen

**Als** Spielleitung **möchte ich** ein Regelsystem (z. B. D&D) als Behälter, der Optionen vorgibt, aus denen die Kampagne wählt (Inventar-, Handwerks-, Reiseregeln), **damit** eine Runde ihre Regeln zusammenstellt, ohne dass Code sie kennt.

## Akzeptanzkriterien

- Ein Regelsystem nennt seine Optionen; die Kampagne wählt je Option.
- Inventar und Handwerk lesen die Wahl der Kampagne.
