# REQ-372 Regeln lernen, wenn sie vorkommen

**Als** Spieler **möchte ich** dass eine Regel für meine Figur als bekannt gilt, sobald sie im Spiel vorgekommen ist, **damit** ich nachschlagen kann, was wir schon erlebt haben, ohne vorab das ganze Regelwerk zu sehen.

## Akzeptanzkriterien

- Eine Regel wird je Spielerin gelernt, wenn sie vorkommt (z. B. ein Zustand wirkt auf die Figur).
- Die Kampagne entscheidet, ob Regeln gelernt werden oder offen liegen.
- Wartet auf Entscheid: E-138.
