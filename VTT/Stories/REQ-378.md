# REQ-378 Regelbuch-PDFs auf dem Server, geteilt nach ihrer Ebene

**Als** Spielleitung **möchte ich** Regelbuch-PDFs auf dem Server ablegen, jedes in der Ebene, zu der es gehört (z. B. die Ebene des Regelwerks), **damit** jeder, der mit dieser Ebene arbeitet, von den Artikeln aus ins Original kommt, auf jedem Gerät.

## Akzeptanzkriterien

- Ein PDF ist ein Asset auf dem Server und gehört genau einer Ebene.
- Geteilt wird nach der Ebene: wer die Ebene sieht (im Stapel der Kampagne, eigene Ebene, Bibliothek), kann das PDF öffnen; hochladen und ersetzen darf, wer in die Ebene schreibt.
- Nie im Repository und nicht im Seed.
- Hover oder Klick auf eine Quellenangabe öffnet das PDF auf Telefon und Desktop.
- Spielende öffnen das PDF, wenn die Ebene mit ihnen geteilt ist (z. B. das PHB-PDF in der PHB-Ebene).
- Ist nur ein Teil der Ebene geteilt (z. B. ohne Monster), sehen sie nur die zugehörigen Teile des PDFs, ohne zusätzliche Kopien im Speicher: der Server setzt beim Öffnen ein Teil-PDF aus den Seiten zusammen, auf die sichtbare Artikel zeigen, dazu Seiten ohne Artikel; Seiten, die nur verborgene Artikel nennen, fehlen; die Leitung kann Seiten sperren (E-194 a).
- Entschieden: E-144, E-194 a (Leitung 26./27.10.2026).
