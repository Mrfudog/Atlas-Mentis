# REQ-378 Regelbuch-PDFs privat ablegen

**Als** Spielleitung **möchte ich** meine Regelbuch-PDFs auf dem Server ablegen, nur für mich sichtbar und auf jedem Gerät nutzbar, **damit** ich von jedem Artikel aus ins Original komme, ohne die Bücher weiterzugeben.

## Akzeptanzkriterien

- Ein PDF ist ein privates Asset je Konto, nie für Spielende sichtbar, nie im Repository.
- Hover oder Klick auf eine Quellenangabe öffnet es auf Telefon und Desktop.
- Wartet auf Entscheid: E-144.
