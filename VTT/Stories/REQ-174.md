# REQ-174 Regeltexte mit Platzhaltern

**Als** Spielleitung **möchte ich** Regeltexte mit Platzhaltern (`{VAR}`) schreiben, die je Verwendung gebunden werden, **damit** eine Regel wie „Waffenangriff“ einmal dasteht und an jedem Statblock passt.

## Akzeptanzkriterien

- Die Bindung liegt an der Kante; der gespeicherte Text bleibt die Vorlage.
- Aufgelöst wird Kante → Artikel → Kampagnenwerte → Register.

## Anmerkungen

Without it, `composedOf` (REQ-053) only reuses rules needing no variation — which is almost none. One "Weapon Attack" rule, bound differently by every statblock — Stand: `{VAR}`: Kante → Artikel → Kampagnenwerte → Register

## Bisheriger Wortlaut

> Parameterised rule templates: `{VAR}` placeholders in RuleElement text, bound per reference; resolution order reference → entity → campaign register
