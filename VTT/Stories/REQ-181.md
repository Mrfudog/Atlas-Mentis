# REQ-181 Freie Felder an einem einzelnen Artikel

**Als** Spielleitung **möchte ich** einem einzelnen Artikel ein Feld geben, das seine Art nicht kennt, und es später in die Art übernehmen, **damit** ich nicht erst das Register ändern muss, um eine Notiz festzuhalten.

## Akzeptanzkriterien

- Ein freies Feld steht an genau einem Artikel.
- „Befördern“ macht es zu einem Feld der Art.

## Anmerkungen

**Conflicts with D2** (`allows` strict). Suggested resolution: unpromoted fields live in a reserved component; promotion is an explicit action that writes the `interface` row — Stand: `adhoc` mit Befördern

## Bisheriger Wortlaut

> Ad-hoc fields on a single entity, promotable into the interface definition
