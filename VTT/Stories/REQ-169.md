# REQ-169 Erkundungsstand

**Als** Spieler **möchte ich** sehen, welche Orte verborgen, entdeckt oder erkundet sind, **damit** die Karte unsere Reise erzählt.

## Akzeptanzkriterien

- Erkunden eines Knotens deckt seine Wege auf.

## Anmerkungen

A progressive-disclosure dimension, adjacent to Visibility but not the same thing — Stand: `Place.state` hidden · discovered · explored

## Bisheriger Wortlaut

> Exploration state ladder per map feature (verborgen → entdeckt → erkundet) with cascade: exploring a node reveals its edges as discovered
