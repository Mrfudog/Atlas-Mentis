# REQ-294 Token ohne Bild zeigt den Anfangsbuchstaben

**Als** Spielleitung **möchte ich** dass ein Token ohne Bild den Anfangsbuchstaben der Kreatur zeigt, bei verdeckter Kreatur den des Decknamens, **damit** Tokens unterscheidbar bleiben, ohne etwas zu verraten.

## Akzeptanzkriterien

- Ohne Bild zeigt das Token den Anfangsbuchstaben.
- Ist die Kreatur verdeckt, stammt er aus dem Decknamen.
