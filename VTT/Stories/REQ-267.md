# REQ-267 Eigenes Netz-VPS mit VPN

**Als** Verwaltung **möchte ich** später den Reverse Proxy auf einem eigenen kleinen Server betreiben, mit VPN ins Heimnetz, **damit** weitere Dienste hinter demselben Zugang laufen können.

## Akzeptanzkriterien

- Reverse Proxy und VPN laufen getrennt von dev und prod.
