# REQ-048 Kreatur schnell bearbeiten

**Als** Spielleitung **möchte ich** die Kernfelder einer Kreatur direkt in der Ansicht bearbeiten, mit der Option „alle Felder bearbeiten“, **damit** kleine Änderungen keinen Formularwechsel brauchen.

## Akzeptanzkriterien

- Ein Klick aufs Feld bearbeitet es; ein Formular gibt es nur beim Anlegen aus einem anderen Artikel.
- Beim Bearbeiten steht jedes Feld als Eingabe da, der Name bleibt Überschrift.
