# REQ-003 Änderungsverlauf je Artikel

**Als** Spielleitung **möchte ich** je Artikel sehen, wer wann was geändert hat, **damit** ich Änderungen nachvollziehe und zurückholen kann.

## Akzeptanzkriterien

- Jede Änderung steht im Protokoll (`event_log`).
- Der Artikel zeigt seinen Verlauf.

## Anmerkungen

Replaces denormalized authors[]; authorship is a query

## Bisheriger Wortlaut

> Change chain: every change as entry (who/when/what) along the version chain, git-log style
