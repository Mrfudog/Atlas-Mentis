# REQ-027 Arten ohne Code anlegen

**Als** Spielleitung **möchte ich** neue Artikelarten mit ihren Feldern anlegen, ohne dass jemand Code ändert, **damit** das Modell mit der Kampagne wächst.

## Akzeptanzkriterien

- Das Register ist Daten mit Masken; eine neue Art ist eine Zeile.
- Liste, Artikelseite und Anlegen zeichnen eine neue Art ohne Vorlage je Art.
