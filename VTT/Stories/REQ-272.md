# REQ-272 Statblock als Instanz einer Vorlage

**Als** Spielleitung **möchte ich** einer Kreatur einen Statblock aus einer Vorlage geben, der nur speichert, was abweicht, **damit** ich eine von zwei Wachen ändere, ohne die andere, und eine Korrektur an der Vorlage alle erreicht.

## Akzeptanzkriterien

- „Aus einer Vorlage“ legt eine Instanz mit `instanceOf` an; beim Lesen liegt die Vorlage darunter (`resolveInstance`).
- Was gleich wie die Vorlage ist, wird beim Speichern verworfen; ↺ am Feld setzt zurück.
- Geht die Vorlage, bekommen die Instanzen vorher, was sie lasen (`detachInstance`).
