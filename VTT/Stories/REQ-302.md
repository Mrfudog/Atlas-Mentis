# REQ-302 Der Filter gehört der Seite

**Als** Spielleitung **möchte ich** dass eine Liste ihren Filter behält, wenn ich von einem Artikel auf sie zurückgehe, **damit** ich ihn nicht jedes Mal neu setze.

## Akzeptanzkriterien

- Typ, Marke und Status leeren sich nur beim Wechsel auf eine andere Seite.
