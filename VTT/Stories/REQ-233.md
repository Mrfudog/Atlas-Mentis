# REQ-233 5e.tools über eine Pipeline laden

**Als** Verwaltung **möchte ich** 5e.tools über eine Pipeline einlesen statt von Hand auf dem Server — einmal, danach nur ergänzen, **damit** der Bestand reproduzierbar hereinkommt und eigene Änderungen bleiben.

## Akzeptanzkriterien

- `import-5etools.yml`, nur von Hand; vorher eine Sicherung, ein Probelauf ist möglich.
- `--only-new` legt nur an, was fehlt; `--replace-layer` nur ausdrücklich.

## Anmerkungen

`.github/workflows/import-5etools.yml` und `deploy/import.sh`; ersetzt wird die Ebene, nicht der Bestand (`--replace-layer`, D67). Ein echter Lauf in GitHub Actions gegen den Server war beim Merge noch nicht geprüft.

## Bisheriger Wortlaut

> 5e.tools über eine Pipeline einlesen statt von Hand auf dem Server: dev von selbst, wenn sich der Importer ändert, prod nur von Hand; vorher eine Sicherung, ein Probelauf ist möglich, der Bericht steht im Lauf
