# REQ-330 Inventory image an einen Gegenstand binden

**Als** Spielleitung **möchte ich** ein Bild mit transparentem Hintergrund hochladen, einem Gegenstand als Inventory image zuweisen und dabei Ausschnitt und Lage an seiner Rasterform einstellen, **damit** Bild und Form zusammenpassen, ohne dass ich das Bild aussen zuschneide.

## Akzeptanzkriterien

- Beim Hochladen wird geprüft, ob das Bild einen Alphakanal hat; leere Ränder werden auf Wunsch abgeschnitten.
- Eine Vorschau legt das Bild auf die Rasterform, so wie sie gemalt ist (keine Grundausrichtung, E-076); Drehung um 90° und Rand lassen sich einstellen.
- Optional ein zweites Bild als Spiegelbild, wenn die Form asymmetrisch ist (aus der Form gerechnet).
- Instanzen lesen das Bild ihrer Vorlage und dürfen ein eigenes haben.
- In der Oberfläche heisst es „Inventory image“, nie „Token“ (E-077).

## Anmerkungen

Nutzt dieselben Bildwerkzeuge wie REQ-298 (Tokens zusammenstellen); das Ergebnis ist aber ein Inventory image eines Gegenstands und kein Token — Token ist die Spielfigur (E-077).
