# REQ-380 Bücher über konfigurierbare Strukturen zerlegen

**Als** Verwaltung **möchte ich** festlegen, wie Überschriften, Kästen und Tabellen eines Buchs auf Module und Artikelarten abgebildet werden, je Verlag ableitbar, **damit** neue Bücher ohne neuen Code hereinkommen.

## Akzeptanzkriterien

- Die Abbildung ist Daten wie eine Ansicht, nicht ein Importer je Buch.
- Eine Abbildung lässt sich je Verlag als Vorlage weitergeben.
- Ein Probelauf zeigt das Ergebnis, bevor geschrieben wird.
- Wartet auf Entscheid: E-147, E-146.
