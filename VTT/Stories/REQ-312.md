# REQ-312 Eigenes Token bewegen

**Als** Spieler **möchte ich** mein Token auf der Karte verschieben und dabei die Reichweite prüfen, **damit** meine Bewegung auf der Karte widergespiegelt wird.

## Akzeptanzkriterien

- Spielende bewegen nur Tokens ihrer eigenen Figuren.
- Der Bewegungsrechner zeigt, wie weit die Figur in diesem Zug kommt.
- Die Bewegung kommt live bei allen an.
