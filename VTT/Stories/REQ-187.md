# REQ-187 Tischanzeige

**Als** Spielleitung **möchte ich** eine Anzeige für einen Bildschirm am Tisch, getrennt von den Konten der Spielenden, **damit** alle dasselbe sehen, ohne dass jemand angemeldet sein muss.

## Akzeptanzkriterien

- Die Anzeige zeigt nur, was alle sehen dürfen.

## Anmerkungen

Every access requirement (REQ-031–036) assumes accounts; a beamer or table tablet has none

## Bisheriger Wortlaut

> Table display mode: a shared read-only presentation view for a screen at the table, distinct from per-player accounts
