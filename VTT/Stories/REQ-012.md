# REQ-012 Textfelder für jede Art von Text

**Als** Spielleitung **möchte ich** Texte verschiedener Art (Absatz, Vorlesetext, Fakt, Geheimnis, Gedicht, Lied) als Felder an einem Artikel erfassen, auch mehrere von einer Sorte, **damit** jeder Text seinen Platz hat und einzeln freigegeben werden kann.

## Akzeptanzkriterien

- Ein Textblock ist ein Feld mit `format: 'long'`, mehrfach mit `many`.
- Jeder Eintrag trägt eine Id aus dem Text, an der die Wissensfreigabe hängt.

## Bisheriger Wortlaut

> Block types: paragraph, readaloud, fact, secret, poem/song/review… extensible list
