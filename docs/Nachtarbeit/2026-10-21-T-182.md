## Punkt 2 — `livesIn`

Regel (`wohnorte.ts`):
- Eine benannte Kreatur (T-169) wohnt dort, wo ihr Statblock (Verweis
  oder `Embed`) im Text **genau eines** Orts steht.
- Innerhalb einer Szene gehört Text zum Ort seiner letzten Überschrift.
- Ein Ort, dem mehr als drei benannte Kreaturen zufallen, ist eine
  Sammelstelle und vergibt keinen Wohnort.

| | Kreaturen |
|---|---:|
| eindeutig (lokal) | 262 |
| in mehreren Orten genannt, nicht gesetzt | 346 |
| nur an einer Sammelstelle, nicht gesetzt | 4 |
| auf dev geschrieben | **220** (2 in der Probe LMoP, `810e13f6-6910-43e5-974d-801e5494d563`; 218 danach, `f1637c07-bddf-42db-a152-7602372091e1`) |
| ausgelassen: Ort auf dev nicht vorhanden | 34 |
| ausgelassen: Kreatur auf dev nicht vorhanden | 8 |

**Befund vor dem Schreiben:** Die erste Fassung der Regel hätte 342
Wohnorte geschrieben. Die Stichprobe (25 von 342) fand, dass eine Szene
wie „Locations in …" den Text vieler Orte trägt: 14 NSC hätten so am
ersten Ort dieser Szene gewohnt, 17 an einer Übersichtskarte. Darum PR
#327 vor dem Schreiben. In der Stichprobe danach (30 von 262) wohnen die
meisten in einem Raum oder Gebäude, das der Text ihnen gibt. Zweifelhaft
bleiben einzelne, die nur in einem Raum vorkommen, in dem sie auftreten
können (z. B. eine Herrscherin im Arbeitszimmer eines Gegners).
