# T-212 — Zauberlisten auf dev (15.10.2026)

Sitzung: https://claude.ai/code/session_017ch6of5fPHnW81Nyxzevk1 · Code: PR #215 (`feature/zauberlisten`).

Die Kante `spellList` (Klasse, Unterklasse → Zauber) auf dev nachgetragen,
nachdem PR #215 (Kante, Migration 093, `addRelation` mit `targets`) dort
ausgerollt war. Keine Inhalte aus 5e.tools in diesem Protokoll — nur
Nummern, Namen der Klassen und Zählungen.

## Ablauf

1. Daten: `5etools-src` (Sparse-Checkout `data`, Stand 90d343c vom
   14.10.2026) ausserhalb des Repos, wie in
   [Betrieb › 5e.tools laden](../Betrieb.md#5etools-laden).
2. Plan: `node packages/import-5etools/dist/cli.js <data> --spell-lists <plan>`
   — 188 819 Artikel, alle geprüft; **185 Klassen und Unterklassen,
   9 241 Kanten**. Die Peg-Ids stimmen mit dev überein (Wizard
   `e5_6bb4b1f90e9e` = `class-0012` im Plan und auf dev).
3. **Probe** (eine Klasse): `zauberlisten-5etools.mjs --only class-0012 --check`
   → Vorschau 1 geändert, 0 abgelehnt, 340 Kanten; geschrieben.
   Massenänderung **`1caded4e-f664-47fb-b153-0f27e40d3e57`**. Danach auf dev
   `GET /api/list?type=Spell&f=in.spellList:e5_6bb4b1f90e9e` → 340 Zauber,
   „Class spell list" ist die erste Facette. Ein zweiter Lauf desselben
   Auftrags änderte nichts (0 geändert) — Kanten kommen nicht doppelt.
4. **Rest**: `--except class-0012 --check` → Vorschau 156 ausgewählt,
   156 geändert, 0 abgelehnt, **7 345 Kanten**; geschrieben.
   Massenänderung **`efa70ad5-1a99-4f32-b84c-3c6b7f8d0f87`**.

Zusammen **157 Klassen und Unterklassen, 7 685 Kanten**. Zurück:
`node scripts/atlas.mjs undo <id>` je Massenänderung.

## Was fehlt

- **28 Klassen und Unterklassen** gibt es auf dev nicht (der Datenstand ist
  neuer als der Bestand auf dev: Bücher EFA, FRHoF, RHW, AU u. a.) — sie
  stehen unten mit „fehlt auf dev". Kommen sie mit einem Lauf `--only-new`
  herein, bringt ein neuer Plan ihre Listen (dieselben Schritte).
- **379 Ziele** (Zauber) gibt es auf dev nicht, aus demselben Grund; `--check`
  liess sie weg (Probe 6, Rest 373).
