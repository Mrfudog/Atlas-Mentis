# Nachtarbeit 21./22.10.2026 — T-351: Wirkungen an den Zustandsartikeln auf dev

Protokoll der Artikeländerung auf **dev** (`https://dev.ttrpg.fuchsbau.io`).
Prod ist nicht angefasst. Im Repo steht nur, was geändert wurde — kein
Regeltext.

## Was

Die `Condition`-Artikel der Ebene „Player's Handbook" trugen keine
Wirkungen (`Effects.effects` leer), also gaben Zustände am Tisch weder
Vorteil noch Nachteil. Nachgezogen mit **einer Massenänderung**
(`set Effects.effects`, `ifEmpty: true`, `allLayers: true`): nur, wo noch
nichts stand.

| Zustand | Wirkungen |
|---|---|
| Blinded | `attack` grant disadvantage · `attacked` grant advantage |
| Invisible | `attack` grant advantage · `attacked` grant disadvantage |
| Restrained | `attack` grant disadvantage · `attacked` grant advantage · `speed.*` limit 0 |
| Prone | `attack` grant disadvantage · `attacked.near` grant advantage · `attacked.far` grant disadvantage |
| Paralyzed | `attacked` grant advantage · `speed.*` limit 0 |
| Stunned | `attacked` grant advantage |
| Unconscious | `attacked` grant advantage · `speed.*` limit 0 |
| Petrified | `attacked` grant advantage · `speed.*` limit 0 |
| Poisoned | `attack` grant disadvantage |
| Grappled | `speed.*` limit 0 |

**Bewusst nicht:** Frightened (der Nachteil gilt nur, solange die Quelle
in Sicht ist — als Wirkung ohne Bedingung wäre er öfter falsch als
richtig), Exhaustion 1–6, Charmed, Deafened, Incapacitated, Surprised,
Concentration (keine Wirkung auf Angriffswürfe oder Tempo, die die
Rechnung heute kennt). Was nur unter einer Bedingung gilt (Nachteil auf
DEX-Rettungswürfe, Krit in 5 ft), braucht eigene Ziele und ist offen.

`attacked.near`/`attacked.far` (Prone) wirken erst mit dem Code aus
T-351; davor zählte der laufende Server nur `attack`.
